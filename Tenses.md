# Tense and aspect

← [[README|Course home]] · [[A2 — Common Verb Forms]]

| Form | Example | Use |
| --- | --- | --- |
| Present | γράφω | I write / I'm writing |
| Imperfect | έγραφα | I was writing / I used to write |
| Aorist | έγραψα | I wrote, with the event presented as a whole |
| Imperfective future | θα γράφω | I will be writing / I will write regularly |
| Perfective future | θα γράψω | I will write, with the action presented as a whole |
| Present perfect | έχω γράψει | I have written |
| Past perfect | είχα γράψει | I had written |
| να + imperfective form | να γράφω | to write regularly or be writing |
| να + perfective form | να γράψω | to write on a given occasion |

**Κάθε μέρα γράφω. Χτες έγραψα ένα μήνυμα. Όταν ήρθες, έγραφα ακόμα. Αύριο θα γράψω ξανά.** — I write every day. Yesterday I wrote a message. When you came, I was still writing. Tomorrow I'll write again.
