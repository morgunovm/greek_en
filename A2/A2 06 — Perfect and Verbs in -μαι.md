# Perfect and verbs in -μαι

← [[A2 — Course Guide]] · [[Tenses]]

Form the present perfect with **έχω** and an invariable verb form: **έχω γράψει**, **έχεις γράψει**, **έχουμε γράψει**. It can describe a result or experience up to now. **Έχω ήδη στείλει το μήνυμα.** — I've already sent the message. With a finished time such as *yesterday*, use the aorist: **Χτες έστειλα το μήνυμα.**

**Δεν έχω πάει ποτέ στην Κρήτη.** — I've never been to Crete. **Έχεις φάει;** — Have you eaten?

| Person | θυμάμαι (remember) | έρχομαι (come) |
| --- | --- | --- |
| εγώ | θυμάμαι | έρχομαι |
| εσύ | θυμάσαι | έρχεσαι |
| αυτός / αυτή / αυτό | θυμάται | έρχεται |
| εμείς | θυμόμαστε | ερχόμαστε |
| εσείς | θυμάστε | έρχεστε |
| αυτοί / αυτές / αυτά | θυμούνται | έρχονται |

Verbs with **-μαι** endings often translate naturally with an English active verb: **Κοιμάμαι νωρίς.** — I go to bed early. The same set of endings can also have passive meaning, as in **Το βιβλίο διαβάζεται εύκολα.** — The book is easy to read. Learn the common pairs **έρχομαι → ήρθα**, **κοιμάμαι → κοιμήθηκα** and **σηκώνομαι → σηκώθηκα**.

Ask a travel question with **Έχεις πάει ποτέ…;** and give two answers using **ήδη** and **ποτέ**.
