# Future, να and aspect

← [[A2 — Course Guide]] · [[Tenses]]

| Pattern | Process or habit | Action as a whole |
| --- | --- | --- |
| Future with θα | θα γράφω | θα γράψω |
| Wanting with να | θέλω να γράφω | θέλω να γράψω |
| Ability with να | μπορώ να γράφω | μπορώ να γράψω |
| Negative future | δεν θα γράφω | δεν θα γράψω |
| Negative after να | να μη γράφω | να μη γράψω |

**Αύριο θα γράψω ένα μήνυμα.** — I'll write a message tomorrow. **Θα γράφω κάθε μέρα.** — I'll write every day. **Πρέπει να φύγω τώρα.** — I have to leave now. **Θέλω να πηγαίνω με τα πόδια.** — I want to go on foot regularly.

Learn the perfective form after **θα / να** alongside the aorist: **έγραψα → θα γράψω**, **είδα → να δω**, **ήρθα → να έρθω**. English can use an infinitive after *want*. Greek uses **να** and a verb ending that identifies who does the action: **Θέλω να έρθεις.** — I want you to come.

**Όταν φτάσω, θα σου τηλεφωνήσω.** — When I arrive, I'll call you. **Πριν φύγω, θα φάω.** — Before I leave, I'll eat.
