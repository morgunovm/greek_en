# Questions, negatives and word order

← [[A1 — Course Guide]] · [[Question Words]]

Turn **Μένεις εδώ.** into **Μένεις εδώ;** with question intonation. Greek has no equivalent of the English question auxiliary *do*. Open questions usually start with a question word.

| Pattern | Example | English |
| --- | --- | --- |
| Ποιος / ποια / ποιο | Ποια είναι η Μαρία; | Which one is Maria? |
| Τι | Τι κάνεις; | What are you doing? / How are you? |
| Πόσο / πόσα | Πόσο κάνει; Πόσα εισιτήρια θέλετε; | How much is it? How many tickets would you like? |
| Πότε / πώς / γιατί | Πότε φεύγεις; Πώς πας; Γιατί φεύγεις; | When are you leaving? How are you getting there? Why are you leaving? |

**Δεν** goes before the indicative verb: **Δεν έχω χρόνο.** — I don't have time. **Όχι** is the stand-alone answer *no*: **Όχι, δεν μένω εδώ.** After **να**, use **μη(ν)**: **Προσπαθώ να μην αργώ.** — I try to be on time.

Subject–verb–object is a useful starting pattern: **Η Μαρία θέλει νερό.** — Maria wants water. When the subject is obvious, **Θέλει νερό.** is enough.
